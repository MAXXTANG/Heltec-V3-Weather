## 寫入方式

每批工作新增 `YYYY-MM-DD-HHMM-工具-主題.md`，時間採 Asia/Taipei；檔名已存在就換唯一名稱，不覆寫舊紀錄。新檔加到本索引頂端。

必填：任務範圍、repository／分支／基線 commit、正式進度來源、修改檔案、實際驗證與未測項、未提交變更、下一步、同步結果。提交 hash 可由 Git 歷史查到；不能預填尚未產生的 commit 或尚未成功的 push。
