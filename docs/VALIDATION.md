## 驗證邊界

新案通知以模擬資料驗證，使用的案件辨識、導覽及繪圖函式與韌體共用。本次沒有等到官方真實新案，因此不宣稱已完成真實新案到 OLED 通知的端到端測試。`new-case-alert-simulation.gif` 為模擬示意。前版 v1.4.0 常規翻頁／倒數測試的按鍵為 USB DTR／GPIO0 模擬；本次 v1.4.1 通知確認則由使用者親自按 BOOT。兩次均未用相機量測光學閃爍。

查詢仍為每輪完成後約 60 秒輪詢；連線、其他網路工作與倒數會延長間隔。短暫重連保留 RAM 中最近 256 案識別；重開機重新建立基準，不把第一輪舊案全部當新通知。
